# Changelog

All notable changes to Dogeared are tracked here.

This project follows semantic versioning for product releases. While Dogeared is pre-1.0, minor releases can include meaningful product changes and patch releases should stay focused on fixes and polish.

## [Unreleased]

## [0.1.0] - 2026-05-08

### Added

- Added Following as a logged-in page for recent shelf activity from readers you follow.
- Added public reader discovery cards and current-following management.
- Added editable book ratings on profile, book, home, and search surfaces.
- Added rating activity support for shelf updates.

### Changed

- Improved mobile navigation with a single-row link layout.
- Improved mobile sticky section headers.
- Improved book card reflow at narrow browser widths.
- Improved profile page section highlighting while scrolling.
- Marked the Book Ratings roadmap item as finished.

### Fixed

- Prevented mobile browser zoom when focusing progress inputs.
- Removed preview/mock reader data from live profile and Following surfaces.
- Fixed left navigation overflow so it does not show unnecessary scrollbars.
